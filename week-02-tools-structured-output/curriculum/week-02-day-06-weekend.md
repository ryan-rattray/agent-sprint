# Week 2, Weekend — Buffer + the Explain Test (Sat–Sun, Oct 17–18)

## The idea

Same as last weekend: the week's binary done criteria aren't all in the code.
They're in your mouth. This week's explain test: **why did schema validation
change the agent's reliability — what class of failures did it eliminate that
Week 1's regex parsing couldn't catch?** If you can answer that out loud with
no notes — right shape vs. right meaning, named errors vs. silent garbage —
you own Week 2. If you stumble, the weekend is your buffer: finish the code
first, then rehearse the explanation.

## What to do

1. **Catch up** on any unfinished day. The week is done when Friday's criteria
   are met, not when Sunday arrives.
2. **The explain test.** Out loud, no notes: (a) walk a tool call from model
   output through schema validation to registry dispatch; (b) explain why a
   404 became an observation instead of a crash; (c) name the failure class
   schema validation killed that regex parsing couldn't.
3. **Week 2 README line.** Add one line to `agent-sprint/README.md`: real
   tools, error contracts, schema-validated calls. (The portfolio skeleton
   keeps growing.)
4. **Park the spillover.** Anything you wanted to add but didn't — headless
   browsers, retry policies, more tools — goes in the sprint parking lot, not
   in the code.
