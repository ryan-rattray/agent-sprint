# Agent Sprint

My 8-week hands-on program to learn AI agent development (Oct 5 – Nov 29, 2026).

One build per week, each with binary done criteria. No frameworks until week 5 —
plain Python first, so the fundamentals are earned, not borrowed.

## Structure

- `week-01-react-loop/` – the ReAct loop from scratch
- `week-02-tools-structured-output/` – tools and structured output
- `week-03-memory-state/` – memory and persistent state
- `week-04-planner-executor/` – planner/executor orchestration
- `week-05-framework-rebuild/` – rebuild week 1 with a framework
- `week-06-evals/` – evaluations
- `week-07-production/` – production concerns
- `week-08-capstone/` – capstone: is a second model as judge worth the cost?
- `common/` – shared utilities
- `notes/` – working notes
