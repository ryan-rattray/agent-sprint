# Week 8, Day 2 — First Vertical Slice (Tuesday, Nov 24)

## The idea

A vertical slice beats a horizontal layer: one thin path from input to
output, working end to end, before any depth. For the judge-cost capstone
that's one agent run judged once with the cost recorded. For the
tool-caller that's one tool called correctly by the specialist. For the
data-analysis default that's one CSV through to one chart. Thin, working,
measurable.

## What you'll build

The thinnest end-to-end path of your frozen capstone, with one measurement
attached.

## Steps

1. **Type the slice.** Input to output, no polish, no extra features. Small
   chunks, tested as you go.
2. **Attach the one measurement that matters** (cost for C1, correct-call
   for C2, a finished chart for the default).
3. **Run it.** If the slice doesn't work, the architecture is wrong, not
   the code. Fix the plan first.
4. **Commit.** `week-08 day-02: first vertical slice with measurement`.
   Breakage log.

## Done criteria (binary)

- [ ] One thin input-to-output path works end to end with its key
      measurement recorded.

## What this unlocks

- **Wed:** depth on the slice that works.
- **Thu:** Thanksgiving. Rest or light review.
- **Fri:** eval and write-up.

## Likely snag

**The slice keeps growing.** If "thin" becomes "the whole system," stop and
cut it in half. A slice you can't finish today isn't a slice.

## When you're done

Reply "Day 2 done". Tomorrow's sheet: building depth.
