# Week 8, Weekend — Packaging and Retrospective (Sat-Sun, Nov 28-29)

## The idea

The last weekend. Two jobs: package the capstone so a stranger can run it
(repo clean, README accurate, demo reproducible), and write the
retrospective: eight weeks, what each week taught, what the system did for
you. The curriculum ends Sunday. The check-ins stop with it.

## What to do

1. **Package.** Fresh-clone test: does the demo run from a clean checkout?
   README accuracy pass. Secrets scrub: full-history grep for key, secret,
   token, and vendor variants before anything goes public. The Week 1
   lesson, applied one last time.
2. **The retrospective.** One paragraph per week, honest. What worked, what
   didn't, what the fence and the parking lot did for you.
3. **Close out the breakage logs.** Read all eight weeks' findings once.
   That's the real portfolio: the bugs you caught and what they taught.
4. **No new code.** The sprint is over; packaging is the work.

## Done criteria (binary)

- [ ] The demo runs from a clean checkout.
- [ ] Retrospective written, breakage logs closed out.

## What this unlocks

Nothing next. That's the point. The curriculum ends here; what continues is
the practice: typed code, binary done criteria, guardrails in code, and the
parking lot.

## When you're done

Reply "Week 8 done" — the curriculum is complete.
