# Week 5, Day 5 — The Verdict (Friday, Nov 6)

## The idea

"Learn it deeply enough to argue with it" was the week's brief, and today
you argue. Whiteboard LangGraph's execution model from memory: what a node
is, what an edge is, where state lives, how a run starts and ends. Then name
two things it does worse than your hand-rolled Week 1 loop. No hedging. The
framework earned its keep or it didn't, and either answer is useful.

## What you'll build

A whiteboard session (paper counts) plus a written verdict: the execution
model in your own words, two weaknesses with evidence, one strength you
didn't expect.

## Steps

1. **Whiteboard the execution model from memory.** No docs open. Photograph
   it for the log.
2. **Write the two weaknesses**, each with the specific moment this week
   that revealed it.
3. **Write the one unexpected strength** the same way.
4. **Commit.** `week-05 day-05: framework verdict with evidence`. Breakage
   log.

## Done criteria (binary)

- [ ] You can whiteboard the execution model from memory.
- [ ] Two weaknesses vs. the hand-rolled loop are named with evidence from
      this week's builds.

## What this unlocks

- **Week 6** (Nov 9-13): evals. You'll build the harness against whichever
  agent you trust more, and now you have a reasoned answer.

## Likely snag

**Confusing familiarity with understanding.** If the whiteboard needs the
docs open, that's data: the model isn't internalized yet. Close the docs and
try again. The gaps show you what to re-read.

## When you're done

Reply "Day 5 done". Weekend sheet: buffer and the explain test.
